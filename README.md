## Projet phare : PowerTech

Vitrine de l’entreprise. Le texte vend le métier. Les sites livrés se partagent
dans la page. La case de paiement prépare le règlement à la livraison.
L’effet visuel est une pluie de 0 et de 1.

**Code :** [`powertech/`](powertech/)

### Lancer en local

```bash
cd powertech
python3 -m http.server 8765
```

Puis ouvrir `http://127.0.0.1:8765`.

Le brief est copié, puis la messagerie s’ouvre vers l’adresse définie
dans `CONTACT_EMAIL`, au début de `powertech/main.js`.

### Ce que montre ce projet

- Multi-pages React (catalogue, fiche, panier, contact)
- Transitions « pluie binaire » 0/1
- Ambiance sonore **générative** (Web Audio, libre de droits)
- Conseiller produit (chatbot PULSE)
- UI responsive, direction visuelle assumée
